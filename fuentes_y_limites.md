# Fuentes y límites

La fuente principal es un informe académico privado de experiencia laboral, de 51 páginas, con capturas históricas. Existe además un CV complementario. No se cuenta con bases originales CRM, XLSX, CSV, PBIX ni código histórico de esta experiencia.

El período detallado es principalmente junio de 2022 a febrero de 2024. El resumen declara continuidad hasta junio de 2024 sin detallar los últimos meses. La portada interior tiene una fecha discordante con la presentación y el cuerpo; se anotó en la auditoría privada y no se utilizó para extender la cronología.

| Afirmación | Límite de interpretación |
|---|---|
| Prototipos aceptados | No prueba despliegue o uso sostenido |
| Usuarios inactivos identificados | No prueba deshabilitación, ahorro ni capacidad liberada |
| Autorregistro revisado | No prueba desarrollo ni implementación de una plataforma |
| Reportes de asistencia actualizados | No implica diseño original del libro |
| Análisis predictivo descrito | No prueba precisión, evaluación fuera de muestra ni nivel senior |
| Campaña y cambio de participación | No prueba causalidad ni efecto cuantificado |

No se reconstruyeron personas, cifras ni datos a partir de capturas. Tampoco se inventó DAX histórico. Las demos usan unidades y reglas nuevas y no completan las lagunas de la experiencia documentada.
