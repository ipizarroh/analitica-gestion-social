# Metodología de documentación

Se revisaron texto y vistas de las 51 páginas del informe privado, con ampliación de la visual de campañas. Se organizó la evidencia por problema de gestión, no por cantidad de capturas. El CV se utilizó como contexto profesional y no como prueba técnica autónoma.

Cada caso remite a un identificador de una matriz privada fuente–afirmación. La matriz registra las páginas físicas del PDF, el rol, la herramienta, el estado y los riesgos. No se publica para evitar distribuir detalle institucional.

| Estado | Significado |
|---|---|
| CONFIRMADO | Documentado en la fuente revisada, sin implicar certificación independiente del empleador |
| PARCIAL | Hay relato o imagen, pero faltan componentes para reproducir o cerrar la afirmación |
| INFERIDO | Interpretación o propuesta actual que no se convierte en hecho histórico |
| NO ACREDITADO | La evidencia disponible no permite sostenerlo |

Se distinguió desarrollo propio, colaboración con BI/TI y mantenimiento. Se excluyeron capturas, nombres ajenos, cifras internas y datos personales. Las demos se crearon desde cero y sus pruebas validan únicamente ese desarrollo posterior.
